Стенд варианта 09 для курса «Инфраструктура как код».

## Создание

Запуск из корня репозитория:

```bash
bash hw-01/create.sh
```

По умолчанию создаются 2 веб-машины.

Количество веб-машин можно изменить:

```bash
bash hw-01/create.sh --web-count 3
```

## Проверка

```bash
bash hw-01/check.sh
echo $?
```

`check.sh` выполняет три проверки:

1. балансировщик отвечает HTTP 200;
2. через балансировщик отвечают обе веб-машины;
3. сервер приложения доступен с веб-сервера по внутреннему адресу.

Код `0` означает успешное прохождение всех проверок, код `1` — наличие ошибки.

## Удаление

```bash
bash hw-01/destroy.sh
```

Скрипт удаляет ресурсы стенда с префиксом `gorelov-09` и продолжает работу, даже если часть ресурсов уже была удалена.
